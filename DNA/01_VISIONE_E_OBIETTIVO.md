# Visione e Obiettivo

## Visione

Realizzare una web app frontend-only, ottimizzata per iPad, per generare menu stampabili con coerenza alta tra anteprima A4, print preview browser e stampa finale.

## Obiettivo operativo

- Leggere dati menu in sola lettura da Google Sheet pubblico.
- Offrire solo 3 viste:
  - `IT`
  - `EN`
  - `EXTERNAL` (sintesi bilingue singola pagina)
- Mantenere UI pulita, minimale, touch-friendly, print-first.

## Vincoli non negoziabili

- Nessun backend.
- Nessun database.
- Nessuna autenticazione.
- Nessuna sezione extra oltre le 3 viste.
- Supporto footer fisso (allergeni + pane/coperto) gia previsto dalla base.
