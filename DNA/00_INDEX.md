# DNA - Indice e Regola di Manutenzione

## Scopo

La cartella `DNA` e la base di conoscenza operativa del progetto.
Deve descrivere in modo sempre coerente visione, architettura, logiche dati e stampa.

## Regola permanente (obbligatoria)

Ogni modifica strutturale, funzionale o architetturale deve includere l'aggiornamento dei file `DNA` interessati nella stessa lavorazione.

## Aggiornamento minimo richiesto

- Aggiornare sempre almeno i file toccati dal cambiamento.
- Aggiornare `10_STATO_ATTUALE.md` quando cambia comportamento visibile.
- Aggiornare `11_MODIFICHE_STEP_CORRENTE.md` a fine step.
- Aggiornare `12_PROSSIMI_STEP_CONSIGLIATI.md` se cambiano priorita.
